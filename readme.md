## Intro

A knife bound to dull over time, and the same applies to our skills. Amidst the rise of AI, one should still sharpen their own blade so it won't lose its edge.

Here I strive to sharpen and polish my skills that I had by writing, reading, and analyzing the code myself. Some might question it: `what's the need for that? `, `you can just ask AI to teach you`, etc. But at some point, we need to be able to rely on ourselves.
